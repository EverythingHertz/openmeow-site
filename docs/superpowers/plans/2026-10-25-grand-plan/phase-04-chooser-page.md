# Phase 4 — The chooser page

## Goal

Replace the homepage with the one-screen chooser: pick a destination, the route lights up, the detail card fills. First visible change of the plan.

## Changes

- `scripts/build-chooser.mjs` (new): emits `index.html` from `ROOMS`, `FLOWS`, `DEMOS`, `CAPABILITY_BRIEFS` and readiness — header, line index, the server-rendered system map, the detail card, footer. Reuses the escaping, picture and brief helpers from `build-world.mjs` by importing them (export them there; no copy).
- `chooser.css` (new): the page's own stylesheet on the design-system tokens; `world.css` is not loaded on the chooser.
- `chooser.mjs` (new): selection by click or hash, hover highlighting, the route draw-on and one-shot travelling marker, keyboard navigation of the index, and card updates. No scroll logic. Ported from `world.mjs`, not rewritten: the motion toggle with its existing `sessionStorage['openmeow-world-paused']` key (`:43-70`, `:279-286`), the image-error class (`:377-384`), and the hidden-target recovery rule (`:403-414`) as a pure function with a test.

`world.html` continues to be generated by `build-world.mjs` and remains reachable as the long document until phase 9.

## Data structures

A **selection**: `{ flowId, source: hash|click|key }`. The **card model** per flow: `{ line, product, stops with notes (gate · held · "change for …"), bring, get, readiness chip, primary action href, catalogue href, story href }` — assembled once at build time into a JSON island so runtime needs no second data source.

## Routing

Architecture: `claude` / `claude-opus-4-6`; implementation: `codex` / `gpt-5.4`; visual review: `claude` with the `frontend-design` and `impeccable` skills.

## Verification

Static: hash routing is a pure function with tests (`#mission-control` selects, unknown selects lobby, no hash selects nothing); build is idempotent under `git diff --exit-code`; `node --check` on `chooser.mjs`. Runtime: page height ≤ 2 × viewport at 1440×1000; every one of the eight lines selectable by mouse, keyboard and hash; no-JS page lists outcomes and products with working links; reduced motion disables the draw-on and marker; screenshots at 1440 and 390 in the browser pane; a keyboard-only traversal recorded in the completion note.
